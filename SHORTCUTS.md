# Excel Keyboard Shortcuts (Windows and Mac)

> Part of the **35-module Excel Mastery** curriculum. See the [curriculum roadmap](README.md) or the other [quick reference guides](README.md#quick-reference-guides).

Shortcuts save more time than almost any other Excel skill. Learn five at a time and use them in real work.

- **Windows** shortcuts are for Excel 2016 and later on Windows.
- **Mac** shortcuts are for Excel on a Mac (Microsoft 365 and Excel 2024). On a Mac, **Cmd** is the Command key and **Option** is the Alt key.
- Microsoft 365 for Mac has added many Windows shortcuts over time (for example F4 and Ctrl + Shift + L work in recent versions), so if a Windows shortcut works on your Mac, use it.
- Mac function keys (F1 to F12) may need the **Fn** key, and macOS can use some combinations for other tasks. Check System Settings, Keyboard, Keyboard Shortcuts if a shortcut does nothing.
- A dash (-) means there is no simple Mac shortcut; use the ribbon or menu.
- Verified as of November 7, 2026 against Microsoft's shortcut lists and independent shortcut guides. Shortcuts can change between versions.

## Move around

| What it does | Windows | Mac |
|---|---|---|
| Jump to the edge of the data block | Ctrl + Arrow | Cmd + Arrow |
| Go to cell A1 | Ctrl + Home | Ctrl + Home |
| Go to the last used cell | Ctrl + End | Ctrl + End |
| Open Go To (jump to a cell, name or range) | Ctrl + G or F5 | Ctrl + G |
| Next sheet | Ctrl + Page Down | Ctrl + Page Down or Option + Right Arrow |
| Previous sheet | Ctrl + Page Up | Ctrl + Page Up or Option + Left Arrow |
| Next open workbook window | Ctrl + Tab | Cmd + ` |
| Move one cell right or left in a selection | Tab or Shift + Tab | Tab or Shift + Tab |
| Move down after entering | Enter | Return |
| Find | Ctrl + F | Cmd + F |
| Find and replace | Ctrl + H | Ctrl + H |

## Top 20 to learn first

1. `F2` edit a cell (Mac: `Ctrl + U`)
2. `F4` lock a reference (Mac: `Cmd + T`)
3. `Alt + =` AutoSum (Mac: `Cmd + Shift + T`)
4. `Ctrl + 1` format cells
5. `Ctrl + T` create a Table
6. `Ctrl + Shift + L` filters (Mac: `Cmd + Shift + F`)
7. `Ctrl + Arrow` jump to the edge of the data
8. `Ctrl + Shift + Arrow` select to the edge
9. `Ctrl + Space` and `Shift + Space` select column and row
10. `Ctrl + D` fill down
11. `Ctrl + E` Flash Fill
12. `Ctrl + Alt + V` Paste Special (Mac: `Ctrl + Cmd + V`)
13. `Ctrl + ;` today's date
14. `Ctrl` + backtick (the key left of the number 1) show formulas
15. `Alt + Enter` new line in a cell (Mac: `Ctrl + Option + Return`)
16. `Ctrl + G` Go To
17. `Ctrl + Z` and `Ctrl + Y` undo and redo
18. `Ctrl + [` select precedents
19. `F9` calculate
20. `Alt, N, V` insert a PivotTable (Windows)
