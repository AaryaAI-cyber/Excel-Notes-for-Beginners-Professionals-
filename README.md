# Excel Notes (Beginners → Professionals)

A beginner-friendly, professional set of **Excel notes** based on the Coursera specialization **Excel Skills for Business** (Macquarie University).  
I’m publishing **one small lesson every day** to stay consistent and build a useful public resource.

## Who this is for
- **Beginners / non-technical learners**: simple explanations + step-by-step instructions
- **Students**: quick revision + practice questions
- **Professionals**: clean references, common mistakes, and practical examples

## How to use this repo
- Start from **Week 1 / Getting Started** if you’re new to Excel.
- If you already know basics, jump to topics you need (functions, formatting, charts, etc.).
- Each lesson includes:
  - What you’ll learn
  - Explanation (simple)
  - Steps (how to do it)
  - Example
  - Common mistakes
  - Practice
  - Quick recap

## Repository structure
- `00-roadmap/` → course info + weekly learning objectives
- `01-interface/` → Excel UI, workbooks/worksheets, navigation, data entry
- `02-calculations/` → formulas, operators, relative vs absolute references
- `03-formatting/` → styles, themes, number formats, formatting datasets
- `04-data/` → worksheets, find/replace, conditional formatting
- `05-printing/` → print setup, scaling, page breaks, print titles
- `06-charts/` → chart types, creating and customizing charts
- `projects/` → mini projects / case studies
- `images/` → screenshots used in lessons

## Daily learning plan (my workflow)
1. Learn a small topic (15–30 minutes)
2. Write one lesson in Markdown
3. Commit + push to GitHub (one meaningful update per day)
