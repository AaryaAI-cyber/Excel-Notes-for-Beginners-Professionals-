# Screenshots folder

This folder is for **real Excel screenshots** that the repository owner can add later.

How to add one:

1. Take a screenshot in Excel (Windows: `Win + Shift + S`, Mac: `Cmd + Shift + 4`).
2. Save it here as a PNG, for example `02_example.png`. Keep each file under 300 KB.
3. Add it to the lesson notes (`../../README.md`) with alt text that describes the picture. Use the same Markdown image pattern as the other pictures in that file, and point the path at the screenshot you saved, for example `images/screenshots/02_example.png`.

The pictures in the parent `images/` folder were drawn with Python from the workbook's real values, so they are accurate but they are not Excel screenshots.
