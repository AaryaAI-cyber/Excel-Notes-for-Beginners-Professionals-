# Glossary

> Part of the **35-module Excel Mastery** curriculum. See the [curriculum roadmap](README.md) for live lesson links as each module publishes.

223 terms from the Jargon Buster boxes of all lessons, in A to Z order. The lesson numbers show where a word is explained in context.

## A

- **Absolute reference**: a reference locked with dollar signs ($B$3) that never moves when copied. _(lessons: 03)_
- **Active cell**: the cell with the thick green border. What you type goes here. _(lessons: 01)_
- **Add-in**: a small program that adds a feature to Excel, such as Claude for Excel. _(lessons: 30)_
- **Aggregate**: to roll many values into one: a total, a count, an average, a maximum. _(lessons: 08)_
- **Amortisation**: paying a loan back in equal instalments that include interest and principal. _(lessons: 22)_
- **API**: an address a program can call to get or send data. _(lessons: 25)_
- **Applied Steps**: the list of recorded steps on the right of the Power Query Editor. _(lessons: 18)_
- **Approximate match**: the lookup finds the closest value that is not bigger than yours. The table must be sorted from small to large. _(lessons: 05)_
- **Argument**: one piece of information you give a function, separated by commas. _(lessons: 04)_
- **Array**: a list or block of values that a formula handles at once. _(lessons: 08, 09)_
- **Autofill**: dragging the fill handle to continue a pattern like Mon, Tue, Wed or 1, 2, 3. _(lessons: 02)_
- **AutoSave**: saving changes automatically for files stored in OneDrive or SharePoint. _(lessons: 28)_
- **Axis**: the horizontal or vertical scale of the chart. _(lessons: 16)_

## B

- **Binary file (.xlsb)**: a compact Excel file format that opens and saves faster on big workbooks. _(lessons: 29)_
- **Boolean**: another name for a TRUE/FALSE value. _(lessons: 04)_
- **Business intelligence (BI)**: tools and methods that turn data into reports and dashboards. _(lessons: 32)_

## C

- **Calculated column**: a column in a table where one formula fills the whole column. _(lessons: 13)_
- **Calculation chain**: the order in which Excel recalculates formulas based on their dependencies. _(lessons: 29)_
- **Capstone**: a final project that combines many skills. _(lessons: 33)_
- **Case question**: a business situation you analyse and explain. _(lessons: 34)_
- **Case-sensitive**: treats "A" and "a" as different. _(lessons: 06)_
- **Category**: the labels along an axis, such as month names. _(lessons: 16)_
- **Cell**: one box on the grid. Its address is the column letter plus the row number, for example B3. _(lessons: 01)_
- **Cell reference**: the address of a cell used inside a formula, such as B2. _(lessons: 03)_
- **Character**: one letter, digit, space or symbol. _(lessons: 06)_
- **Cheat sheet**: a short summary for quick lookup. _(lessons: 35)_
- **Circular reference**: a formula that refers to its own cell, directly or through other cells. _(lessons: 11)_
- **Co-authoring**: several people editing the same workbook at the same time. _(lessons: 28)_
- **Colour scale**: a gradient from one colour to another across the values in a range. _(lessons: 14)_
- **Column index number**: the number of the column in the table that holds the answer (the 1st column is 1). _(lessons: 05)_
- **Combo chart**: a chart that mixes types, for example columns plus a line. _(lessons: 16)_
- **Comment and note**: a comment is a threaded conversation on a cell. A note is a simple sticky note. _(lessons: 28)_
- **Comparison operator**: a symbol that compares two values: = < > <= >= <> (not equal). _(lessons: 04)_
- **Concatenate**: to join pieces of text into one (with & or TEXTJOIN). _(lessons: 06)_
- **Concentration risk**: dependence on one customer, product or region. _(lessons: 31)_
- **Conditional formatting**: formatting that appears only when a cell meets a rule. _(lessons: 14)_
- **Constraint**: a rule that limits the answer, such as hours available are at most 100. _(lessons: 20)_
- **Context**: the information you give the AI (headers, sample rows, goal, Excel version). _(lessons: 30)_
- **Conversion rate**: the share of leads who become customers. _(lessons: 23)_
- **Copilot**: Microsoft's AI assistant, including the Copilot pane in Excel. _(lessons: 30)_
- **Correlation**: how strongly two measures move together, from -1 to 1. It does not prove that one causes the other. _(lessons: 21)_
- **CPL**: cost per lead, spend divided by leads. _(lessons: 23)_
- **Criteria**: the rule a cell must meet, such as "North" or ">=10". _(lessons: 08)_
- **Criteria range**: the cells that are checked against the rule. _(lessons: 08)_
- **Cross-tab**: a table that counts answers for two questions together (role by age group). _(lessons: 24)_
- **CSV**: comma-separated values, a plain text table that most tools can export. _(lessons: 25)_
- **Custom format**: a format you write yourself, such as 00000 or #,##0.0. _(lessons: 02)_

## D

- **Dashboard**: a one-page view of KPIs and charts built from your data. _(lessons: 17)_
- **Data bar**: a bar inside the cell whose length matches the value. _(lessons: 14)_
- **Data cleaning**: finding and fixing errors, duplicates, blanks and inconsistent formats in a data set. _(lessons: 12)_
- **Data dictionary**: a table that explains each column of the data. _(lessons: 33)_
- **Data label**: the number written on a bar, point or slice. _(lessons: 16)_
- **Data Model**: a hidden database inside the workbook that holds many tables and the links between them. _(lessons: 19)_
- **Data Table**: a grid that recalculates a formula for many input values at once. _(lessons: 20)_
- **Data type**: the kind of value in a cell: number, text, date/time or TRUE/FALSE. _(lessons: 02)_
- **Data validation**: rules on a cell that decide what may be typed there. _(lessons: 12)_
- **Data-ink ratio**: a design idea: most of the ink on a chart should show data, not decoration. _(lessons: 17)_
- **Database**: a system that stores tables of data and answers queries, such as PostgreSQL or SQL Server. _(lessons: 32)_
- **DataFrame**: a table of data in pandas, like an Excel range with named columns. _(lessons: 27)_
- **Date unit**: the letter in DATEDIF that says what to count: "Y" years, "M" months, "D" days. _(lessons: 07)_
- **DAX**: Data Analysis Expressions, the formula language of Power Pivot and Power BI. _(lessons: 19)_
- **Default**: the result used when none of the conditions match. _(lessons: 04)_
- **Defect density**: defects found divided by the size of what was tested (tests, features or code). _(lessons: 25)_
- **Delimiter**: a character that separates parts of a text, such as the @ in an email or a comma. _(lessons: 06)_
- **Deliverable**: the thing you hand in: a workbook, a one-page summary, a short note. _(lessons: 33)_
- **Dimension table**: a short table that describes things (Products, Regions, Dates). _(lessons: 19)_
- **Drill-down**: moving from a summary to the rows behind it. _(lessons: 17)_
- **Dropdown list**: a data validation rule that lets users pick from a list. _(lessons: 12)_
- **Duplicate**: a row (or value) that appears more than once when it should appear once. _(lessons: 12)_
- **Dynamic array**: a formula whose result resizes automatically when the data changes. _(lessons: 09)_

## E

- **Edge case**: an unusual input that may break a formula (blank, zero, duplicate). _(lessons: 34)_
- **Encryption**: scrambling the file so it needs a password to open. _(lessons: 28)_
- **Error trapping**: wrapping a formula so that an error is replaced with a chosen value. _(lessons: 11)_
- **Error value**: a special result such as #DIV/0! that tells you something went wrong in a formula. _(lessons: 11)_
- **Eta-reduced lambda**: passing a plain function name such as SUM instead of writing LAMBDA(x,SUM(x)), as GROUPBY allows. _(lessons: 10)_
- **Exact match**: the lookup must find exactly the value you gave (FALSE in VLOOKUP, 0 in MATCH). _(lessons: 05)_
- **Excel Table**: a named, formatted block of data with filters and automatic growth (Ctrl + T). _(lessons: 13)_

## F

- **Fact table**: a long table of events or transactions (Sales). _(lessons: 19)_
- **Field**: a column of your source data, such as Region or Revenue. _(lessons: 15)_
- **Fill handle**: the small square at the bottom-right corner of the active cell. Drag it to copy. _(lessons: 01)_
- **Filter**: show only the rows that meet a rule and hide the others (the data is not deleted). _(lessons: 13)_
- **Fiscal year**: a company's accounting year, which may not start in January. _(lessons: 07)_
- **Flash Fill**: Excel spots your pattern from an example and fills the rest (Ctrl + E). _(lessons: 02)_
- **Formula**: an instruction that starts with = and tells Excel to calculate something. _(lessons: 03)_
- **Formula bar**: the long box above the grid that shows what is really inside the active cell. _(lessons: 01)_
- **Formula rule**: a rule that uses a TRUE/FALSE formula, giving you full control. _(lessons: 14)_
- **Freeze Panes**: a View setting that keeps the top rows or left columns visible while you scroll.
- **Function category**: a group such as Math, Text, Date or Lookup. _(lessons: 35)_
- **Future value (FV)**: what money will be worth later after interest. _(lessons: 22)_

## G

- **General format**: the default format. Excel guesses what to show. _(lessons: 02)_
- **Goal Seek**: finds the one input value that makes a result equal a target. _(lessons: 20)_

## H

- **Hallucination**: an AI answer that sounds right but is wrong or invented, such as a function that does not exist. _(lessons: 30)_
- **Hard-coded number**: a number typed into a formula or a calculation cell instead of an input cell. _(lessons: 29)_
- **Header row**: the first row of a table that holds the column names.
- **Helper function**: a function that takes a LAMBDA, such as MAP, REDUCE, SCAN, BYROW and BYCOL. _(lessons: 10)_
- **Holiday list**: a range of dates that NETWORKDAYS and WORKDAY skip. _(lessons: 07)_
- **Hyperlink**: a clickable link to a web page, file, sheet or cell.

## I

- **Icon set**: small arrows, flags or traffic lights shown by value. _(lessons: 14)_
- **Implicit intersection**: the old behaviour where Excel quietly picked one value from a range. The @ sign marks it. _(lessons: 09)_
- **Include argument**: in FILTER, the TRUE/FALSE test that decides which rows stay. _(lessons: 09)_
- **Input cell**: a cell you can change (price, rate, units). _(lessons: 20)_
- **Insight**: a finding that leads to an action, not just a number. _(lessons: 33)_
- **IRR**: internal rate of return: the discount rate that makes the NPV zero. _(lessons: 22)_

## J

- **JSON**: a text format for structured data, used by most web APIs. _(lessons: 25)_

## K

- **Key column**: a column of unique IDs used to match two tables. _(lessons: 05)_
- **KPI**: key performance indicator, a number that tells you how you are doing against a goal (revenue, attainment, defect rate). _(lessons: 17, 31)_

## L

- **LAMBDA**: a function that creates a custom function from a formula. You can save it as a named function. _(lessons: 10)_
- **Leading and lagging indicator**: a leading indicator predicts the result (pipeline, leads); a lagging one reports it (revenue, profit). _(lessons: 31)_
- **LET**: a function that gives a name to a value or calculation inside one formula. _(lessons: 10)_
- **Likert scale**: a rating scale such as 1 (strongly disagree) to 5 (strongly agree). _(lessons: 24)_
- **Load**: send the finished query result to a worksheet or to the data model. _(lessons: 18)_
- **Locked cell**: a cell that cannot be changed while the sheet is protected. _(lessons: 28)_
- **Logical test**: a question Excel can answer with TRUE or FALSE, such as G2>=4. _(lessons: 04)_
- **Lookup value**: the thing you search for, such as an employee ID. _(lessons: 05)_

## M

- **M language**: the formula language behind the steps. You can read and edit it. _(lessons: 18)_
- **Macro**: a saved set of actions that Excel can repeat. _(lessons: 26)_
- **Margin**: profit as a share of revenue. _(lessons: 31)_
- **Margin of error**: how far a survey percentage might be from the true value because you asked only a sample. _(lessons: 24)_
- **Mean and median**: the average (sum divided by count) and the middle value. The median is less affected by extreme values. _(lessons: 21)_
- **Measure**: a DAX formula that calculates when the pivot needs it, using the current filters. _(lessons: 19)_
- **Merge and Append**: Merge joins tables side by side (like a lookup). Append stacks tables on top of each other. _(lessons: 18)_
- **Mixed reference**: only the row or only the column is locked, such as $A9 or B$8. _(lessons: 03)_

## N

- **Name Box**: the box left of the formula bar that shows the address or name of the selected cell.
- **Named range**: a cell or range with a friendly name, such as TaxRate, that you can use in formulas. _(lessons: 03)_
- **Nested IF**: an IF placed inside another IF to handle more than two outcomes. _(lessons: 04)_
- **Net margin**: net profit divided by revenue. _(lessons: 23)_
- **NPS**: Net Promoter Score: percent of promoters (9 to 10) minus percent of detractors (0 to 6) on a 0 to 10 recommend question. _(lessons: 24)_
- **NPV**: net present value: the sum of future cash flows discounted to today, minus the investment. A positive NPV adds value. _(lessons: 22)_
- **Number format**: a rule that changes how a value is shown without changing the value stored. _(lessons: 02)_

## O

- **Object**: a thing VBA can control: a Workbook, a Worksheet, a Range. _(lessons: 26)_
- **Office Scripts**: automation scripts written in TypeScript that run on Excel workbooks (Automate tab). _(lessons: 27)_
- **Operator**: a symbol that does a job in a formula: + - * / ^ & = < > <= >= <>. _(lessons: 03)_
- **Outlier**: a value far away from the rest, which may be an error or a real surprise. _(lessons: 12)_

## P

- **p-value**: the chance of seeing a result at least this strong if nothing really differs. Below 0.05 is the usual rule of thumb for "significant". _(lessons: 21)_
- **pandas**: a Python library for tables of data (DataFrames). _(lessons: 32)_
- **Parameter**: a name for an input of a LAMBDA, like x or price. _(lessons: 10)_
- **Pass rate**: tests passed divided by tests run. _(lessons: 25)_
- **Pivot cache**: Excel's saved copy of the source data. Refresh it to bring in changes. _(lessons: 15)_
- **PivotTable**: an interactive summary table built from a list of data. _(lessons: 15)_
- **Portfolio**: a collection of your best work that you show to employers. _(lessons: 33, 34)_
- **Power Automate**: Microsoft's cloud flow tool that can run Office Scripts on a schedule or a trigger. _(lessons: 27)_
- **Power BI**: Microsoft's business intelligence tool for interactive dashboards and data models. _(lessons: 32)_
- **Power Pivot**: the add-in (window) used to manage the Data Model, relationships and DAX. _(lessons: 19)_
- **Power Query**: Excel's built-in tool (Data tab, Get & Transform Data) for importing and shaping data. _(lessons: 18)_
- **Practical test**: a timed exercise where you solve tasks in a workbook. _(lessons: 34)_
- **Precedent**: a cell that a formula depends on. _(lessons: 11)_
- **Precedent and dependent**: a precedent feeds a formula; a dependent uses a cell's value. _(lessons: 29)_
- **Present value (PV)**: what a future amount is worth today. _(lessons: 22)_
- **Print area**: the part of a sheet that will be printed.
- **Procedure (Sub)**: a block of VBA code that does one job. It starts with Sub and ends with End Sub. _(lessons: 26)_
- **Prompt**: the instruction you give an AI tool. _(lessons: 30)_
- **PY function**: the Excel function that holds Python code for a cell (=PY(...)). _(lessons: 27)_
- **Python in Excel**: a feature that runs Python code in cells, using libraries such as pandas and matplotlib, in a secure Microsoft cloud container. _(lessons: 27)_

## Q

- **Query**: a saved recipe of steps that produces a table. _(lessons: 18, 32)_
- **Quick Access Toolbar**: the small row of buttons above or below the Ribbon that you can customise. _(lessons: 35)_

## R

- **R-squared**: the share of the variation the line explains (0 to 1). _(lessons: 21)_
- **Range**: a group of cells, written with a colon, for example A1:C5. _(lessons: 01)_
- **Reconciliation**: proving two independent calculations give the same total. _(lessons: 29)_
- **Refresh**: bring new data into pivots, charts and Power Query results. _(lessons: 17)_
- **Regression**: finding the straight line that best predicts one measure from another. _(lessons: 21)_
- **Relationship**: a link between two tables on a matching column, such as Product. _(lessons: 19)_
- **Relative reference**: a reference that shifts when you copy the formula (B2 becomes B3 one row down). _(lessons: 03)_
- **Reorder level**: the stock level at which you order more. _(lessons: 23)_
- **Reshape**: change the layout of data: stack, split, take, drop, rows to columns. _(lessons: 10)_
- **Result cell**: a cell that depends on the inputs through a formula (profit, payment). _(lessons: 20)_
- **Reverse coding**: flipping a scale for negatively worded questions so that high always means good. _(lessons: 24)_
- **Ribbon**: the strip of tabs and buttons at the top (Home, Insert, Formulas and so on). _(lessons: 01)_
- **Ribbon key tips**: pressing Alt in Windows shows letters you can type to reach any ribbon button. _(lessons: 35)_
- **ROI**: return on investment, (gain minus cost) divided by cost. _(lessons: 23)_
- **Rubric**: a checklist that shows how the work will be judged. _(lessons: 33)_
- **Rule**: the condition and the format to apply, for example "greater than 1000, fill green". _(lessons: 14)_
- **Run-rate**: the year-end result if the recent pace continued, for example half-year revenue times two. _(lessons: 31)_

## S

- **Sample and population**: a sample is part of the group; the population is everyone. STDEV.S is for samples and STDEV.P for populations. _(lessons: 21)_
- **Scenario**: a saved set of input values, such as Worst, Base and Best. _(lessons: 20)_
- **Sensitivity label**: a tag such as Confidential that an organisation applies to files to control sharing. _(lessons: 28)_
- **Serial number**: how Excel stores a date: a whole number that counts days. A time is stored as a fraction of a day. _(lessons: 02, 07)_
- **Series**: one set of values drawn on the chart, such as the revenue of one region. _(lessons: 16)_
- **Sheet tab**: the label at the bottom of the window that names a worksheet.
- **Shortcut**: a key combination that does a task without the mouse. _(lessons: 35)_
- **Sign convention**: money you pay out is negative and money you receive is positive. _(lessons: 22)_
- **Silent error**: a wrong result that shows no error, usually the most dangerous kind. _(lessons: 11)_
- **Slicer**: a set of buttons that filter a table or pivot table with a click. _(lessons: 13, 15)_
- **Solver**: an add-in that finds the best answer (maximum, minimum or target) with several inputs and rules. _(lessons: 20)_
- **Sort**: put rows in order (A to Z, smallest to largest, newest to oldest). _(lessons: 13)_
- **Spaced practice**: reviewing something at growing time gaps so it sticks. _(lessons: 35)_
- **Sparkline**: a tiny chart that sits inside one cell. _(lessons: 16)_
- **Spill**: when one formula writes its answer into several cells at once. The blue border shows the spill range. _(lessons: 09)_
- **Spill error**: #SPILL!, when a dynamic array cannot fill its range. _(lessons: 11)_
- **Spill range**: the cells the formula fills. Keep them empty or you get #SPILL!. _(lessons: 09)_
- **SQL**: Structured Query Language, used to ask a database for data. _(lessons: 32)_
- **Standard deviation**: a number that shows how spread out the values are around the mean. _(lessons: 21)_
- **STAR**: Situation, Task, Action, Result, a way to answer behavioural questions. _(lessons: 34)_
- **Status bar**: the strip at the bottom of the Excel window that shows live totals for selected cells.
- **String**: another word for text, a chain of characters. _(lessons: 06)_
- **Structured reference**: a formula reference by table and column name, like tblSales[Revenue]. _(lessons: 13)_
- **Sum range**: the cells that are added when the rule is met. _(lessons: 08)_

## T

- **Table array**: the range that holds the data you search in. _(lessons: 05)_
- **Target attainment**: actual divided by target, shown as a percentage. _(lessons: 17)_
- **Template**: a ready-made file you copy and fill in, such as a budget or invoice.
- **Test run**: one execution of a set of test cases. _(lessons: 25)_
- **Text to Columns**: a Data tool that splits one column into several at a delimiter or fixed width. _(lessons: 12)_
- **Time value of money**: money today is worth more than the same money later, because it can earn interest. _(lessons: 22)_
- **Timeline**: a slicer for dates that filters by month, quarter or year. _(lessons: 15)_
- **Top-2-box**: the share of respondents who chose the top two answers (4 or 5). _(lessons: 24)_
- **Trust Center**: Excel's security settings for macros. _(lessons: 26)_
- **TypeScript**: JavaScript with types. Office Scripts use it. _(lessons: 27)_

## U

- **Unpivot**: turn many columns (such as Q1, Q2, Q3) into rows so the data is tidy. _(lessons: 18)_

## V

- **Values area**: the box where you drop the field to be added, counted or averaged. _(lessons: 15)_
- **Variance**: the difference between actual and plan. _(lessons: 23, 31)_
- **VBA**: Visual Basic for Applications, the programming language behind macros. _(lessons: 26)_
- **VBE**: the Visual Basic Editor, where you read and write code (Alt + F11). _(lessons: 26)_
- **Verification**: checking an answer with an independent method. _(lessons: 30)_
- **Volatile function**: a function such as TODAY() or NOW() that recalculates every time Excel recalculates. _(lessons: 07, 29)_

## W

- **Walk-through**: explaining your work step by step while you do it. _(lessons: 34)_
- **Wildcard**: a stand-in character: ? is any one character and * is any number of characters. _(lessons: 06, 08)_
- **Wildcard characters**: the ? (any one character) and * (any characters) used in criteria, SEARCH and Find.
- **Workbook**: the Excel file itself (like a ring binder). _(lessons: 01)_
- **Working days**: Monday to Friday, without weekends or listed holidays. _(lessons: 07)_
- **Worksheet**: one tab inside the workbook (like one page in the binder). _(lessons: 01)_

## X

- **xlsb**: a compact binary Excel file type that opens fast for large workbooks.
- **xlsm**: an Excel file type that can store macros.
- **xlsx**: the normal Excel file type. It cannot store macros.

## Z

- **Zoom**: a setting that makes the worksheet look bigger or smaller without changing the data.
